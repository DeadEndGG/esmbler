# Esmbler.Hosting

Composition root shared by the API, MCP, and worker hosts: service registration, JWT authentication, configuration binding, and the demo tenant seed (`DemoTenants.cs`, which names Tickets IDs only through `TicketsIds`: Acme on Tickets 1.0.0, Globex on the newest release with Jamie as approver). `ServiceRegistration` registers the kernel services (including `WorkspaceCreationPolicy` and `WorkspaceService`), event consumers (including `ApprovalConsumer`) and job handlers (`upgrade.run`, `workflow.migrate`, `approval.expire`, `sla.check`, `notify.resolve`, `notify.deliver`) and the notification service (`SubscriptionRouter`, `NotificationService`, the channel adapters `SmtpEmailChannel` and `HttpSmsChannel` as `INotificationChannel`, `EnvironmentSecretStore` as `ISecretStore`); a new consumer, job kind or channel adapter is registered here (modules cannot contribute channels).

- Settings: `PlatformOptions` binds the `Esmbler` section (environment `Esmbler__*`); for example `MetricRequestsPerMinute` (default 120) sets the per-person `figures` rate limit the API applies to `/api/dashboards`, `/api/metrics` and `/api/records/{entity}/groups` (ADR 0019); `AllowWorkspaceCreation` (default false: self-service creation is an operator decision) and `MaxWorkspacesPerPerson` (default 5) govern self-service workspace creation (ADR 0020); Compose sets them to true and 100 for local development and acceptance runs. `POST /api/workspaces` has its own fixed per-person rate limit (`LoginThrottle.WorkspacePolicy`, 3 a minute, in the API). `Notifications` (ADR 0021) holds `AllowedEmailHosts` (default empty: email can only be captured; `Esmbler__Notifications__AllowedEmailHosts__0=smtp.example.com`), `AllowedSmsHosts` (default `api.twilio.com`) and `MaxRecipientsPerEvent` (default 200); `ServiceRegistration` maps them to `NotificationOptions` together with `Esmbler:WebUrl` (links in messages, default `http://localhost:8080`). Compose sets none of them. Channel credentials are `ESMBLER_SECRET__<WORKSPACE_SLUG>__<NAME>` environment variables, never `Esmbler__*` settings.
- Invariants: secrets only from environment/configuration; API tokens use audience `esmbler-api`, MCP tokens `esmbler-mcp` (no passthrough).
