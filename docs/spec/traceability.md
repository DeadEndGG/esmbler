# Traceability matrix

Status values: `planned`, `in-progress`, `done` (implemented and verified), `deferred` (moved to a later gate with a reason).

Source sections refer to `docs/spec/master-spec.md` (MS) and `docs/spec/execution-brief.md` (EB).
