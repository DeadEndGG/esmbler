# Documentation index

Esmbler's documentation is docs-as-code. It is organized with the Diátaxis framework (tutorials, how-to guides, reference, explanation), plus project records. Update this index whenever a doc is added or moved. Entries marked *planned* do not exist yet; the gate says when they arrive. Items first planned for Gate 1 that were not written are marked *deferred from Gate 1*.
